# 什亭之窗 · 下载版

记忆大厅动态壁纸、阿罗娜与普拉娜桌宠，以及一个灵动岛。

## 下载

前往 [最新版本](https://github.com/km-E100/ShittimWindow/releases/latest) 下载本体：

| 平台 | 安装文件 | 要求 |
| --- | --- | --- |
| Windows | `ShittimWindow-0.7.3-Windows-x64.exe` | Windows 10/11 x64 |
| macOS | `ShittimWindow-0.7.3-macOS-arm64.dmg` | Apple Silicon，macOS 13 或更高 |
| Android | `ShittimWindow-0.7.3-Android.apk` | Android 8 或更高 |

Windows 文件是直接运行的安装程序，不需要解压，也不要把扩展名改成 `.zip`。Mac 打开 DMG 后将应用拖入“应用程序”。Android 下载 APK 后按系统提示安装。

## 本体和壁纸分开下载

本体已经包含两小只、角色语音、灵动岛和一张白子演示壁纸。首次启动即可使用内置内容。

完整壁纸库在 [ShittimWindow-Wallpapers](https://github.com/km-E100/ShittimWindow-Wallpapers) 发布，共 **282 个记忆大厅**。打开记忆大厅设置，点击 **下载完整壁纸库**，应用会依次下载、校验和安装六个分包，不需要手动逐个导入。安装完成后可离线使用。

下载量约 2.67 GB，安装期间请预留至少 6 GB 空间。需要能访问 GitHub 和 `raw.githubusercontent.com`。下载中断后重试，会复用已完成并通过 SHA-256 校验的分包；未完成的分包重新下载。下载或校验失败时继续保留原有壁纸。

## 首次使用

- Android：按首次启动向导依次开启悬浮窗和无障碍，再唤出两小只与灵动岛。厂商系统仍可能需要允许后台运行。
- Mac：需要桌面互动时，按应用提示开启所需系统权限。
- 桌面端：在记忆大厅中启用桌面壁纸；陪伴设置里调整桌宠、语音、字幕和自动避让。
- Windows 灵动岛默认收在顶部，鼠标移到屏幕顶部中央展开；Android 支持顶部触摸。
